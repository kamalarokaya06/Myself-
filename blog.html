My Journey Into Web Development

A short reflection on learning HTML, CSS and the process of creating my first portfolio website.

Starting With HTML

When I first started learning web development, HTML seemed confusing because there were many different elements to remember. Gradually, I understood that HTML provides the structure of a webpage.

Learning headings, paragraphs, links, images, lists, tables and semantic elements helped me understand how a webpage is organised.

Discovering CSS

After learning HTML, I started working with CSS. This was one of the most enjoyable parts because CSS allowed me to change colours, fonts, spacing, borders and layouts.

I learned about Flexbox, Grid, responsive design and media queries. These concepts helped me create a website that works on different screen sizes.

Debugging and Improving

Debugging has been one of the biggest challenges during my learning experience. Small mistakes in file paths, HTML structure or CSS selectors can change the appearance of an entire page.

Instead of becoming frustrated, I learned to check the code carefully, use browser developer tools and validate my HTML and CSS.

What I Have Learned

Web development is not only about writing code. It also involves planning, design, testing, debugging and understanding the needs of users. I am looking forward to developing these skills further throughout my degree.
